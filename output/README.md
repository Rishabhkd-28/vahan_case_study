# Output Files

This folder contains the generated results for the Vahan case study.

- `vahan_case_study_report.md`: final written analysis
- `vahan_case_study_outputs.xlsx`: Excel workbook with aggregate tables, model metrics, confusion matrix, lift, and feature importance
- `aggregation_query.sql`: SQL query for lead-source aggregation
- `cohort_aggregation.csv`: aggregate cohort table
- `model_metrics.csv`: model comparison metrics
- `confusion_matrix.csv`: final model confusion matrix
- `model_feature_importance.csv`: top model features
- `top_cohorts_ft_rate.svg`: cohort ranking chart
- `funnel_summary.svg`: funnel volume chart
